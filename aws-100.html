☁️ Cloud Basics & Global Infrastructure
Q1 – Q6 Foundations

Understanding what AWS is, its core benefits, the three cloud service models, and the key geographic building blocks — Regions, Availability Zones, and Edge Locations — is the foundation of every other AWS topic.

Q1What is AWS?
AWS (Amazon Web Services) is a cloud computing platform that provides on-demand computing services like servers, storage, networking, databases, AI, and analytics using a pay-as-you-go pricing model.
Q2What are the main benefits of AWS?
Scalability, high availability, cost-effective pricing, security, flexibility, and global infrastructure.
Q3What are the types of cloud computing models?
  • IaaS (Infrastructure as a Service): You manage OS, data, and apps (e.g., EC2).
  • PaaS (Platform as a Service): AWS manages the OS and runtime; you just bring code (e.g., Elastic Beanstalk).
  • SaaS (Software as a Service): Completely managed application (e.g., Microsoft 365, AWS Honeycode).
Q4What is an AWS Region?
A region is a geographic area where AWS has multiple, physically isolated data centers.
Q5What is an Availability Zone (AZ)?
An AZ consists of one or more discrete data centers with redundant power, networking, and connectivity within an AWS Region.
Q6What is an Edge Location?
Edge locations are endpoints used by CloudFront (CDN) and Route 53 (DNS) to cache and deliver content with ultra-low latency to global users.
Key distinction: Region → AZ → Edge Location. Regions contain multiple AZs for fault tolerance. Edge locations are much more numerous than AZs and serve only caching/DNS — not general compute.
🔐 Identity & Access Management (IAM)
Q7 – Q10 Security Foundation

IAM is the global service that controls who can do what in your AWS account. Understanding Users vs Roles vs Policies is critical for both security design and exam questions.

Q7What is AWS IAM?
Identity and Access Management controls access to AWS resources securely using authentication (who you are) and authorization (what you can do).
Q8What is the difference between an IAM User and an IAM Role?
  • IAM User: A permanent identity with long-term credentials (password / access keys) mapping to a specific person or application.
  • IAM Role: An identity with temporary credentials meant to be assumed by trusted entities (like an EC2 instance or an external user) without sharing permanent keys.
Q9What is an IAM Policy?
A JSON document that explicitly defines permissions (Allows or Denies) to access specific AWS resources.
Q10What is MFA in AWS?
Multi-Factor Authentication adds an extra layer of security by requiring a second verification factor (like a software token) beyond a standard password.
Security Best Practice
Never use the root account for day-to-day tasks. Create individual IAM users, enforce MFA on the root account and privileged users, and use Roles instead of long-term access keys for applications running on AWS.
🖥️ Compute — EC2 & Auto Scaling
Q11 – Q18, Q37, Q38, Q97 Core Compute · Containers

EC2 is the backbone of AWS compute. Know the instance families, how AMIs, Auto Scaling, and ELB work together to build scalable, highly available applications.

Q11What is Amazon EC2?
Elastic Compute Cloud provides resizable, on-demand virtual servers (instances) in the cloud.
Q12What are the EC2 instance types?
  • General Purpose: Balanced compute, memory, and networking.
  • Compute Optimized: High-performance processors.
  • Memory Optimized: Fast performance for large datasets in memory.
  • Storage Optimized: High, sequential read/write for local storage.
  • Accelerated Computing (GPU): Hardware accelerators for machine learning / graphics.
Q13What is an AMI?
An Amazon Machine Image is a pre-configured template (containing an OS, application server, and applications) used to launch EC2 instances.
Q97What is AMI baking?
The process of fully pre-configuring an AMI with all necessary software, security patches, and dependencies installed so instances boot up quickly without needing startup scripts.
Q14What is Auto Scaling?
A service that dynamically adjusts the number of EC2 instances up or down based on current demand or scheduled policies.
Q15What is an Elastic Load Balancer (ELB)?
Automatically distributes incoming application traffic across multiple targets, such as EC2 instances, containers, and IP addresses.
Q16What are the types of Load Balancers in AWS?
  • Application Load Balancer (ALB): Routes traffic at Layer 7 (HTTP/HTTPS) level; supports path/host routing rules.
  • Network Load Balancer (NLB): Routes traffic at Layer 4 (TCP/UDP) for ultra-high performance and low latency.
  • Gateway Load Balancer (GWLB): Deploys and manages third-party virtual network appliances.
Q17What is a Security Group?
A virtual firewall acting at the instance level to control allowed inbound and outbound traffic.
Q18What is a Key Pair?
A set of security credentials (public key stored by AWS, private key kept by you) used to securely log into EC2 instances via SSH or RDP.
Q37What is Amazon ECS?
Elastic Container Service is a highly scalable container orchestration service that supports Docker containers, letting you run and manage containerized applications without managing the underlying cluster infrastructure.
Q38What is AWS Fargate?
A serverless compute engine for containers that works with both ECS and EKS. Fargate eliminates the need to provision and manage servers — you specify CPU and memory, and AWS runs the containers.

📦 Storage — S3, EBS, EFS
Q19 – Q30, Q76 – Q78 Object · Block · File

AWS storage spans three paradigms — object (S3), block (EBS), and file (EFS). Knowing when to use each, plus S3's rich feature set, is heavily tested.

S3 — Object Storage
Access: Web URL / API (anywhere)
Best For: Images, videos, backups, static websites
EBS — Block Storage
Access: Attached to 1 EC2 instance at a time
Best For: Boot volumes, transactional databases
EFS — File System
Access: Shared across thousands of EC2 instances
Best For: Shared app data, content management
Q21What is Amazon S3?
Simple Storage Service is an object storage platform designed to store and retrieve any amount of data from anywhere on the web.
Q22What are S3 buckets?
Globally unique logical containers used to organize and store objects within S3.
Q23What is S3 versioning?
A mechanism to preserve, retrieve, and restore every version of every object stored in a bucket, guarding against accidental deletion or overwrites.
Q24 & Q30What is an S3 Lifecycle Policy / Object Lifecycle Management?
Automated rules that optimize storage costs by moving objects to cheaper storage tiers or permanently deleting them after a set period.
Q25What are the S3 storage classes?
  • Standard: High durability, availability, and frequent access.
  • Standard-IA: Infrequent access, but requires rapid availability when needed.
  • One Zone-IA: Lower cost, stored in a single AZ (less resilient).
  • Glacier Flexible Retrieval: Low-cost archive; retrieval within minutes to hours.
  • Glacier Deep Archive: Lowest cost; retrieval time within 12 hours.
Q27What is S3 replication?
Automated, asynchronous copying of objects across buckets — in the same region (SRR) or different regions (CRR).
Q28What is a pre-signed URL?
A temporary URL generated by an owner to grant time-limited access to private objects without altering bucket permissions.
Q29What is an S3 event notification?
An alert feature that triggers downstream services (like Lambda or SQS) automatically whenever a specific event occurs, such as an object upload.
Q19What is EBS?
Elastic Block Store provides high-performance, persistent block-level storage volumes for use with Amazon EC2 instances.
Q20What is the difference between EBS and Instance Store?
  • EBS: Persistent storage. Data survives an instance stop/termination.
  • Instance Store: Ephemeral (temporary) storage physically attached to the host computer. Data is permanently lost if the instance stops or terminates.
Q76What is EFS?
Elastic File System provides a serverless, fully managed, elastic network file system that can be shared simultaneously among thousands of EC2 instances.
Q77What is FSx?
Fully managed, high-performance file systems for specific commercial engines: FSx for Windows File Server and FSx for Lustre.
Q78What is Storage Gateway?
A hybrid cloud storage service that gives on-premises environments access to virtually unlimited cloud storage via local caching.
Cost order (cheapest → most expensive): Glacier Deep Archive → Glacier Flexible Retrieval → One Zone-IA → Standard-IA → Standard. Use lifecycle policies to automate tier transitions automatically.
🌐 Networking — VPC & Traffic Routing
Q31 – Q40, Q91 – Q93 VPC · DNS · CDN

VPC is your isolated cloud network. Mastering subnets, gateways, route tables, and the Security Group vs NACL distinction is essential for architecting secure systems.

Q31What is a VPC?
Virtual Private Cloud is a logically isolated virtual network dedicated to your AWS account.
Q32What is a Subnet?
A designated segment of an IP address range inside a VPC where you can isolate resources.
Q33What are the types of subnets?
  • Public Subnet: Connected directly to an Internet Gateway; resources have public IPs.
  • Private Subnet: Isolated from the open internet; resources use internal IPs only.
Q34What is an Internet Gateway (IGW)?
A horizontally scaled, redundant VPC component that allows communication between instances in your VPC and the open internet.
Q35What is a NAT Gateway?
Allows resources in a private subnet to securely initiate outbound traffic to the internet while preventing incoming connections from the internet.
Q36What is a Route Table?
A set of rules (routes) used to determine where network traffic from your subnet or gateway is directed.
Q37What is VPC Peering?
A networking connection that allows you to route traffic between two VPCs privately using private IP addresses.
Q38What is an AWS VPN?
Creates a secure, encrypted IPsec tunnel over the public internet between your on-premises network and your AWS VPC.
Q39What is AWS Direct Connect?
A cloud service that establishes a dedicated, physical network connection bypassing the public internet entirely — from your premises to AWS.
Q40What is the difference between a Security Group and a NACL?
  • Security Group: Operates at the instance level, supports Allow rules only, and is stateful (inbound traffic allowed is automatically permitted back out).
  • Network ACL (NACL): Operates at the subnet level, supports Allow and Deny rules, and is stateless (return traffic must be explicitly allowed).
Q91What is CloudFront?
A global content delivery network (CDN) service that securely delivers data, videos, applications, and APIs to users with low latency.
Q92What is Route 53?
A highly available, scalable Domain Name System (DNS) web service that routes user requests to internet applications.
Q93What is an Elastic IP?
A static, public IPv4 address allocated to your account that can be rapidly remapped to another instance to mask instance failures.

🗄️ Databases
Q41 – Q48, Q50 RDS · DynamoDB · Cache

AWS offers managed relational (RDS, Aurora), NoSQL (DynamoDB), analytical (Redshift), and caching (ElastiCache) services. Know which engine to choose and the HA/scaling options within each.

Q41What is Amazon RDS?
Relational Database Service makes it easy to set up, operate, and scale a relational database in the cloud.
Q42What are the supported RDS engines?
MySQL, PostgreSQL, MariaDB, Oracle, Microsoft SQL Server, and Amazon Aurora.
Q43What is Amazon Aurora?
A cloud-native, high-performance relational database engine fully compatible with MySQL and PostgreSQL, built for the cloud with up to 5× MySQL throughput.
Q47What is Multi-AZ in RDS?
An architectural deployment model that automatically provisions a synchronous standby replica in a different AZ for High Availability / Disaster Recovery.
Q48What is a Read Replica?
An asynchronous copy of a primary database used to offload read traffic and improve read scaling / performance.
Q44What is DynamoDB?
A fully managed, serverless NoSQL key-value and document database designed for single-digit millisecond performance at any scale.
Q45What is Redshift?
A fast, fully managed, petabyte-scale data warehouse service used to run complex analytical queries over massive datasets.
Q46What is ElastiCache?
A fully managed in-memory data store and caching service (supporting Redis and Memcached) used to speed up application read latency.
Q50What is a database snapshot?
A point-in-time, storage-level backup of a database instance.

Multi-AZ vs Read Replica
Multi-AZ = High Availability (synchronous standby, automatic failover). Does NOT improve read performance. Read Replica = Read Scaling (asynchronous copy, manual promotion). Does NOT provide automatic HA failover.
⚡ Serverless & Event-Driven Architecture
Q51 – Q55 · SNS · SQS Lambda · API GW · Messaging

Serverless removes infrastructure management. Lambda, API Gateway, Step Functions, and EventBridge form the core event-driven building blocks in AWS.

Q51What is AWS Lambda?
A serverless compute service that lets you run code in response to events without provisioning or managing underlying servers.
Q52What are some common Lambda triggers?
S3 bucket uploads, API Gateway HTTP requests, DynamoDB data modifications (Streams), and CloudWatch time-based (scheduled) events.
Q53What is API Gateway?
A fully managed service for creating, publishing, maintaining, monitoring, and securing REST, HTTP, and WebSocket APIs at scale.
Q54What is Step Functions?
A serverless visual workflow orchestrator used to sequence multiple AWS services and Lambda functions into step-by-step applications.
Q55What is EventBridge?
A serverless event bus that makes it easy to connect applications together using data from your own apps, SaaS applications, and AWS services.
SNSWhat is Amazon SNS?
Simple Notification Service is a fully managed pub/sub messaging service that enables you to decouple microservices and distribute messages to a large number of subscribers (email, SMS, HTTP, Lambda, SQS) simultaneously.
SQSWhat is Amazon SQS?
Simple Queue Service is a fully managed message queuing service that enables decoupling and scaling of microservices and distributed systems. Messages are stored in the queue until a consumer processes and deletes them.
SNS vs SQS
SNS (push): One message fans out to many subscribers at once (pub/sub). SQS (pull): Messages queue up and a single consumer pulls and processes each one. Common pattern: SNS → SQS (fan-out to multiple queues for parallel processing).
Event-driven pattern: An event source (S3, DynamoDB, API GW) triggers Lambda → Lambda processes and writes to a destination (DynamoDB, S3, SQS). Step Functions orchestrate multi-step Lambda workflows with retries, branching, and parallel execution.
📊 Monitoring, Governance, & Pricing
Q56 – Q60, Q74 – Q75 CloudWatch · CloudTrail · Config

Operational visibility comes from CloudWatch (metrics/alarms), CloudTrail (API audit logs), and AWS Config (compliance tracking). Cost Explorer and Trusted Advisor add cost and best-practice guidance.

Q56 & Q57What is CloudWatch & CloudWatch Metrics?
A monitoring and management service that collects performance data (Metrics like CPU utilization) to give you operational visibility into applications and infrastructure.
Q58What is a CloudWatch Alarm?
A watch configuration that monitors a single metric over a specified time period and performs actions (sending an SNS alert or triggering Auto Scaling) if a threshold is crossed.
Q59What is CloudTrail?
An auditing and governance service that logs and tracks all API calls and account activity — Who did What, When, and From Where.
Q60What is AWS Config?
A service that continuously monitors, records, and evaluates the configuration history of your AWS resources to ensure compliance with best practices.
Q74What is Cost Explorer?
A management tool that enables you to visualize, understand, and analyze your AWS spending and usage over time.
Q75What is Trusted Advisor?
An online tool that provides real-time recommendations across five categories: Cost Optimization, Security, Fault Tolerance, Performance, and Service Limits.

🔒 Security & Identity Services
Q61 – Q65 · Inspector · Shared Resp. KMS · WAF · Shield · Cognito

AWS security services protect data at rest (KMS), secrets (Secrets Manager), application traffic (WAF), DDoS attacks (Shield), and user authentication (Cognito).

Q61What is KMS?
Key Management Service makes it easy to create and manage cryptographic encryption keys used to protect your data across AWS services.
Q64What is Secrets Manager?
A service designed to securely store, rotate, manage, and retrieve secrets like database credentials, API keys, and passwords.
Q62What is AWS Shield?
A managed DDoS protection service that safeguards applications running on AWS. Shield Standard is free; Shield Advanced offers enhanced protection with 24/7 DRT support.
Q63What is AWS WAF?
A Web Application Firewall that helps protect web applications from common exploits like SQL injection and Cross-Site Scripting (XSS).
Q65What is AWS Cognito?
A service that provides easy user sign-up, sign-in, and access control to your web and mobile applications.
Shared ResponsibilityWhat is the Shared Responsibility Model?
A framework defining who is responsible for what in the cloud:
  • AWS is responsible for security of the cloud: Physical hardware, data centers, networking infrastructure, hypervisor, and managed service software.
  • Customer is responsible for security in the cloud: Operating systems, application code, data, IAM configurations, network/firewall settings, and encryption.
InspectorWhat is AWS Inspector?
An automated security assessment service that continuously scans EC2 instances, container images (ECR), and Lambda functions for software vulnerabilities and unintended network exposure, then provides prioritized findings.

🛠️ DevOps, Migration, & Enterprise Management
Q66 – Q72 IaC · CI/CD · PaaS

Infrastructure as Code (CloudFormation), managed deployment (Elastic Beanstalk), and the AWS CI/CD suite (CodeCommit, CodeBuild, CodeDeploy, CodePipeline) form the DevOps backbone on AWS.

Q70What is Infrastructure as Code (IaC)?
The practice of provisioning and managing computing infrastructure using machine-readable configuration files rather than physical hardware configuration or interactive tools.
Q71What is CloudFormation?
AWS's native Infrastructure as Code service that allows you to model, provision, and update your entire AWS resource stack using JSON or YAML templates.
Q72What is Elastic Beanstalk?
An easy-to-use PaaS service for deploying and scaling web applications developed with Java, .NET, PHP, Node.js, Python, Ruby, Go, and Docker — without managing the underlying infrastructure.
OpsWorksWhat is AWS OpsWorks?
A configuration management service that provides managed instances of Chef and Puppet — tools that automate server configuration, deployment, and management across your instances.
SSMWhat is AWS Systems Manager?
Provides visibility and control of your infrastructure on AWS. Key capabilities include: Run Command (execute scripts remotely), Parameter Store (secure config/secrets storage), Patch Manager (automate OS patching), and Session Manager (browser-based shell without SSH).
Cloud9What is AWS Cloud9?
A cloud-based IDE accessible in a web browser, with built-in code completion, a debugger, and a terminal with direct AWS CLI access — no local setup required.
CodeStarWhat is AWS CodeStar?
A unified project dashboard that provides a single place to manage software development activity: quickly set up a CI/CD pipeline, track issues, and monitor builds — integrating CodeCommit, CodeBuild, CodeDeploy, and CodePipeline.

CloudFormation vs Elastic Beanstalk
CloudFormation: Full control over every AWS resource — you define everything in a template. Best when you need precise infrastructure configuration. 🎯 Scenario & How-To Questions
SC1 – SC11 Architecture · Operations · Security

Practical scenario questions test your ability to apply AWS knowledge to real-world problems: migrations, HA design, DR, CI/CD, cost optimization, logging, and networking.

SC1How would you migrate an on-premises application to AWS?
  • Assess: Inventory the app, dependencies, and data using AWS Migration Hub or Application Discovery Service.
  • Choose a strategy: Rehost (lift-and-shift to EC2), Replatform (move to RDS/Elastic Beanstalk), or Refactor (re-architect using serverless/containers).
  • Migrate: Use AWS Database Migration Service (DMS) for databases and AWS Server Migration Service (SMS) or Application Migration Service for servers.
  • Validate: Run in parallel, test thoroughly, then cut over.
SC2How do you ensure high availability on AWS?
  • Deploy resources across multiple Availability Zones.
  • Use Elastic Load Balancing to distribute traffic and detect unhealthy targets.
  • Configure EC2 Auto Scaling to replace failed instances automatically.
  • Use RDS Multi-AZ for automatic database failover.
  • Design with stateless application tiers so any instance can serve any request.
SC3How do you secure data at rest in S3?
  • Enable Server-Side Encryption (SSE) — use SSE-S3 (AWS-managed keys) or SSE-KMS (customer-managed keys via KMS).
  • Apply S3 bucket policies and IAM policies to restrict access to authorized principals only.
  • Block public access using the S3 Block Public Access setting.
  • Enable S3 Versioning to protect against accidental deletion.
SC4How do you handle disaster recovery on AWS?
Choose a DR strategy based on RTO/RPO requirements:
  • Backup & Restore: Lowest cost, highest RTO. Regularly back up data to S3 and restore from snapshots when needed.
  • Pilot Light: Core infrastructure (DB) always running; app servers launched on failover.
  • Warm Standby: Scaled-down but fully functional copy in another region; scale up on failover.
  • Multi-Site Active-Active: Full production stack in multiple regions; fastest RTO/RPO, highest cost.
SC5How do you monitor AWS resources?
  • CloudWatch: Collect metrics (CPU, memory, custom), set alarms, create dashboards, and stream logs via CloudWatch Logs.
  • CloudTrail: Audit all API calls — who changed what, when, and from where.
  • AWS Config: Track resource configuration changes and evaluate compliance rules over time.
  • AWS Health Dashboard: Monitor service events that may affect your account.
SC6How do you optimize costs in AWS?
  • Right-size instances: Use CloudWatch metrics and Compute Optimizer to match instance size to actual usage.
  • Reserved Instances / Savings Plans: Commit to 1–3 year usage for up to 72% discount vs on-demand.
  • Spot Instances: Use for fault-tolerant, interruptible workloads (batch jobs, CI/CD) at up to 90% discount.
  • S3 Lifecycle Policies: Auto-transition objects to cheaper storage tiers.
  • Cost Explorer + Billing Alerts: Track spending trends and set budget alarms.
SC7How do you implement CI/CD on AWS?
  • Source: Store code in CodeCommit (or GitHub).
  • Build & Test: CodeBuild compiles code and runs unit/integration tests.
  • Deploy: CodeDeploy pushes the artifact to EC2, Lambda, or ECS.
  • Orchestrate: CodePipeline ties all stages together, with optional manual approval gates between stages.
SC8How do you manage secrets and credentials on AWS?
  • Use AWS Secrets Manager to store, rotate, and retrieve secrets (DB passwords, API keys) — supports automatic rotation with Lambda.
  • Use Systems Manager Parameter Store for application configuration values (non-secret or encrypted with KMS).
  • Never hardcode credentials in code or environment variables; use IAM Roles for applications on AWS services.
  • Set least-privilege IAM policies on who can access each secret.
SC9How do you scale a web application on AWS?
  • Compute: EC2 Auto Scaling group with scale-out/in policies based on CPU or request count.
  • Traffic: Application Load Balancer distributes requests across all healthy instances.
  • Caching: CloudFront caches static assets at the edge; ElastiCache caches hot database queries.
  • Database: RDS Read Replicas offload read traffic; Aurora Auto Scaling adds read replicas on demand.
  • Sessions: Store session state in ElastiCache or DynamoDB (not on instance) to keep app tier stateless.
SC10How do you implement logging on AWS?
  • CloudTrail: Enable in all regions; send logs to an S3 bucket for long-term retention and audit.
  • CloudWatch Logs: Install the CloudWatch agent on EC2; use log groups for application, OS, and access logs.
  • VPC Flow Logs: Capture IP traffic metadata for network troubleshooting and security analysis.
  • S3 Access Logs / ALB Access Logs: Enable per-service access logging to S3 for request-level audit trails.
  • CloudWatch Alarms & Dashboards: Set threshold alerts on log-based metrics (e.g., error rate spikes).
SC11How do you set up a VPC with public and private subnets?
  1. Create a VPC with a CIDR block (e.g., 10.0.0.0/16).
  2. Create public subnets (e.g., 10.0.1.0/24) and private subnets (e.g., 10.0.2.0/24) — preferably across multiple AZs.
  3. Attach an Internet Gateway (IGW) to the VPC.
  4. Update the public subnet route table: add a route 0.0.0.0/0 → IGW.
  5. Create a NAT Gateway in the public subnet.
  6. Update the private subnet route table: add a route 0.0.0.0/0 → NAT Gateway.
  7. Place public-facing resources (ALB, bastion) in public subnets; databases and app servers in private subnets.
DR strategy selection: RTO = how fast you need to recover. RPO = how much data loss is acceptable. Lower RTO/RPO = higher cost. Match strategy to business requirements: Backup & Restore for dev/test; Warm Standby or Active-Active for production mission-critical systems.
